# python-pandas

Описание проекта 
данный проект направлен на расчет и анализ ключевых ежедневных продуктовых метрик интернет-магазина. 
цель — предоставить бизнесу прозрачную картину активности пользователей, конверсии в покупку и динамики выручки, очищенную от фродовых (заблокированных) аккаунтов и незавершенных транзакций.
в проекте реализован процесс, который собирает сырые логи пользовательской активности и транзакций, агрегирует их по дням и обогащает оконными функциями для расчета динамики роста/падения метрик.

использовал 
Python: `pandas`, `numpy`.
рассчитываемые метрики
dau (daily active users) уникальные активные пользователи в день
daily Buyers уникальные пользователи, совершившие успешную оплату в день
daily Revenue суммарная выручка от успешно оплаченных заказов
dau difference разница в dau по сравнению с предыдущим днем (отслеживание трендов)
diff from Max DAU: отклонение текущего DAU от исторического максимума
buyer conversion (%): конверсия из дневной активности в покупку (Daily Buyers / DAU)
особенности реализации
решение проблемы пропущенных дат: использована генерация непрерывного календаря (`pd.date_range` в Python). это гарантирует, что дни без активности не выпадут из итогового отчета, а получат значения `0` (через .fillna()`).
безопасность вычислений: предусмотрена обработка деления на ноль при расчете конверсии (`np.where` в Python).
